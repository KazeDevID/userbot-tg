# userbot-tg — Telegram Userbot & Selfbot Engine

> Modern, lightweight Telegram Userbot & Selfbot Engine powered by native MTProto. Transforms your personal Telegram account into a high-speed personal automation bot without bot tokens or webhooks.
>
> **Watermark: by KazeDevID**

## 🌟 What is userbot-tg?

Unlike standard Telegram bots that require a bot token from @BotFather, **userbot-tg is a true Userbot / Selfbot**. It logs directly into your personal Telegram account via Telegram's native **MTProto protocol** (the exact same protocol used by official Telegram apps).

### Key Features
- **In-Place Message Editing**: When you type `.ping`, `> 2+2`, or `$ uptime`, your account immediately edits your own message with the result in real time.
- **Prefixless Eval (>) & Exec ($)**: Evaluate JavaScript with `> <code>` and execute terminal commands with `$ <cmd>` without any prefix. Immediate raw output replaces your message without any prefix.
- **Clean Menu Response**: The `.help` and `.menu` list response displays a clean command catalog without descriptions.
- **No Bot Tokens or Webhooks**: Pure MTProto TCP/WebSocket connection directly to Telegram Data Centers (DC 1–5).
- **Persistent String Session**: Authenticate once via terminal login to generate a portable string session. No need to re-login on restart.
- **Smart AFK Responder**: Automatically notifies users who mention or direct message you while you are away, and logs when you return.
- **Chat Management**: Fast message purge, instant deletion, member tagging, and user inspection.
- **100% Modern JavaScript**: ES Modules, async/await, clean architecture, no single-line comments.

## 🚀 Quick Start

### 1. Prerequisites
- **Node.js**: Version 18.0.0 or higher
- **Telegram API Credentials**: Get `API_ID` and `API_HASH` from [my.telegram.org/apps](https://my.telegram.org/apps)

### 2. Installation
Clone the repository:
```bash
git clone https://github.com/KazeDevID/userbot-tg.git
cd userbot-tg
npm install
```

### 3. Generate String Session
Run the interactive login script in your terminal:
```bash
npm run login
```
You will be prompted for:
1. Your **API ID** (e.g. `1234567`)
2. Your **API HASH** (e.g. `0123456789abcdef0123456789abcdef`)
3. Your **Phone Number** with country code (e.g. `+628123456789`)
4. The **Login Code** sent to your Telegram app
5. Your **Two-Factor Password** (if 2FA is enabled on your account)

The script will generate and print your **STRING_SESSION**.

### 4. Configuration
Create a `.env` file in the root directory:
```bash
cp .env.example .env
```

Populate it with your credentials:
```env
API_ID=1234567
API_HASH=0123456789abcdef0123456789abcdef
STRING_SESSION=1BVtsOHQBu7...your_string_session...
COMMAND_PREFIX=.
```

### 5. Launch userbot-tg
```bash
npm start
```
Open your Telegram app on your phone or desktop and send `.ping` or `.alive` in any chat!

## ⚙️ Configuration Variables

| Variable | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `API_ID` | Number | **Yes** | Your Telegram API ID from my.telegram.org |
| `API_HASH` | String | **Yes** | Your Telegram API Hash from my.telegram.org |
| `STRING_SESSION` | String | **Yes** | Base64 MTProto session string generated by `npm run login` |
| `COMMAND_PREFIX` | String | No (default `.`) | Prefix for userbot triggers (e.g. `.`, `!`, `,`) |

## 💬 Available Commands

Send these commands from your personal Telegram account:

### ⚡ Developer & Execution (Prefixless Triggers & Direct Output)
- `> <code>` (or `.eval <code>`) — Evaluates JavaScript expression directly without prefix. Direct raw output replaces the message instantly.
- `$ <cmd>` (or `.exec <cmd>`) — Executes terminal shell command directly without prefix. Direct raw stdout/stderr replaces the message instantly.

### ⚡ System Diagnostics
- `.ping` — Calculates message editing latency and MTProto server roundtrip speed.
- `.alive` — Displays userbot status banner and account specs.
- `.uptime` — Shows how long the userbot has been running.
- `.info` — Detailed technical breakdown of the engine.

### 👤 Selfbot & Personal Automation
- `.afk [reason]` — Activates Away-From-Keyboard mode. Auto-replies when mentioned.
- `.unafk` — Manually deactivates AFK mode.
- `.type <message>` — Creates an animated typewriter effect in the current chat.
- `.whois [reply]` — Inspects the replied user's profile ID, username, and details.
- `.block [reply]` — Blocks the replied user.

### 🧹 Chat Administration
- `.purge [count]` — Deletes your own recent outgoing messages (default 10, max 100).
- `.del` — Reply to any message to delete it instantly.
- `.pin [reply]` — Pins the replied message.
- `.tagall [text]` — Mentions group participants for announcements.

### 🛠️ Utilities
- `.calc <expression>` — Solves arithmetic expressions (e.g., `.calc (45 * 12) / 3`).
- `.b64 <enc|dec> <text>` — Base64 encoder and decoder.
- `.quote` — Prints an inspiring software engineering quote.
- `.id` — Displays your user ID, current chat ID, and replied message metadata.
